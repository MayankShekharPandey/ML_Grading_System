
# Automated Student Answer Grading System

## Project Overview
A Machine Learning-based Automated Short Answer Grading System using the ASAG2024 dataset.

## Algorithms Implemented
1. Hidden Markov Model (HMM)
2. Random Forest
3. Third machine learning algorithm

## Dataset
- cleaned_ASAG2024_train(1).csv
- cleaned_ASAG2024_test.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- MLflow
- Jupyter Notebook

## Experiment Tracking
MLflow is used for experiment tracking, hyperparameter
optimization, model comparison and performance evaluation.

## Project Files
- Three Jupyter notebooks containing model implementations.
- Two CSV datasets.
- Two MLflow backup files containing saved experiment information.

## Purpose
Academic Machine Learning project demonstrating
automated answer grading and MLflow experiment tracking.
